# Birthday Website Images

Folder ini berisi gambar-gambar untuk website ulang tahun.

## Struktur Folder

```
images/
├── photos/          # Foto-foto kenangan
├── backgrounds/     # Gambar background
└── icons/           # Icon custom
```

## Cara Menambahkan Foto

1. Simpan foto di folder `photos/`
2. Format yang disarankan: JPG, PNG, WebP
3. Ukuran optimal: 800x800px untuk gallery

## Tips
- Kompres gambar untuk loading yang lebih cepat
- Gunakan format WebP untuk ukuran file yang lebih kecil
