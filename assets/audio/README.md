# Birthday Website Assets

Folder ini berisi file audio untuk website ulang tahun.

## Cara Menambahkan Audio

1. **Birthday Music**: Simpan file musik sebagai `birthday-music.mp3`
2. **Voice Message**: Simpan pesan suara sebagai `voice-message.mp3`

## Format yang Didukung
- MP3 (disarankan)
- WAV
- OGG
